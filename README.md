# After school map

A map of after-school programs within walking distance or a short bus or subway ride of a home in north Park Slope, Brooklyn, for two kids (L and S). Every fact on the page links to the page it came from.

Live: https://joshgreenman1973.github.io/after-school-map/

- Walking times: shortest path on the OpenStreetMap pedestrian network (streets, sidewalks, crosswalks, park paths), 3 mph.
- Bus and subway times: MTA static schedules, weekday 3 to 6:30 p.m., single-seat trips only.
- Program facts: each program's own website, checked Sept. 29, 2026, with the verbatim line that supports each fact.

The map is drawn from OpenStreetMap data (© OpenStreetMap contributors, ODbL), NYC borough boundaries and MTA station data.
